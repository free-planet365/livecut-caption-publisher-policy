Livecut Caption Publisher

チャンネル運営者が、自身の動画へ日本語字幕・翻訳字幕・翻訳タイトルと説明を登録するためのデスクトップツールです。

審査準備用の公開資料
このページはアプリの配布サイトではありません。プライバシーポリシーと利用規約は草案です。APIデータの保管・削除運用を確認した後に正式施行し、監査申請を完成させます。

対象とする機能

運営者が用意したYTT字幕ファイルをYouTube Data API v3へ送り、対象動画の言語別字幕として登録・更新します。日本語・英語・韓国語・繁体字中国語・簡体字中国語・スペイン語の6言語に対応します。翻訳にはOpenAI APIを使用します。

動画はYouTube上で視聴します。翻訳字幕はYouTubeプレイヤーの字幕機能で選択できます。対応チャンネル：ホロライブ速報【切り抜きch】。

操作の流れ

  1. 運営者が対象動画と字幕ファイルを指定します。
  2. Google OAuth 2.0で、運営者が管理するアカウントの認可を行います。
  3. 字幕の検査を行い、未解決の翻訳を含む言語は公開を保留します。
  4. 字幕・翻訳メタデータを登録し、成功した操作をローカルの進捗ファイルへ記録します。
  5. 同じ内容の再実行では成功済みの字幕を省略し、未完了分を再開します。

使用するYouTube API

操作用途
captions.list既存字幕の確認
captions.insert / updateYTT字幕ファイルの登録・更新
videos.list / updateタイトル・説明の取得と多言語メタデータ更新

OAuthスコープ：https://www.googleapis.com/auth/youtube.force-ssl。このページからGoogleアカウントの認可を行う機能はなく、ログイン情報を入力するフォームもありません。プログラム、APIキー、OAuthトークン、録画素材はこの公開サイトに掲載しません。

利用条件とデータの取り扱い

本ツールはYouTube APIサービスを使用します。YouTube利用規約、Googleプライバシーポリシーをご確認ください。詳しい取り扱いはプライバシーポリシー案と利用規約案に記載しています。
